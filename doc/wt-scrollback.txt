*wt-scrollback.txt*	Vim as Windows Terminal's scrollback pager

Requires Vim 9.1 with |+vim9script| and |+textprop|, Windows Terminal (tested
with 1.24) and Windows PowerShell.

						*wt-scrollback*
Windows Terminal's scrollback opens in Vim with ctrl+shift+h, over the
current pane and with its colors, view, cursor and font size as on screen,
also of a pane running Vim or ssh.

	q, i	Close the pager.
	y	Yank, also to the clipboard.

						*:WtScrollbackSetup*
:WtScrollbackSetup
	Adds the settings below to Windows Terminal's settings.json, which
	Windows Terminal loads by itself. The old file is kept as {file}.bak,
	comments and the rest of the file stay as they are.

settings.json: >
	"disableAnimations": true,
	"actions": [
	    {
	        "command": {
	            "action": "multipleActions",
	            "actions": [
	                { "action": "selectAll" },
	                { "action": "copy", "singleLine": false,
	                  "copyFormatting": "html" },
	                { "action": "splitPane", "split": "down", "size": 0.2,
	                  "profile": "{7b7965fa-a70a-5652-bcf0-a02e57f39683}" },
	                { "action": "togglePaneZoom" }
	            ]
	        },
	        "id": "User.WtScrollback",
	        "name": "Open scrollback in Vim"
	    }
	],
	"keybindings": [
	    { "id": "User.WtScrollback", "keys": "ctrl+shift+h" }
	],
	"profiles": {
	    "list": [
	        {
	            "name": "wt-scrollback.vim",
	            "guid": "{7b7965fa-a70a-5652-bcf0-a02e57f39683}",
	            "hidden": true,
	            "commandline": "\"C:\\...\\vim.exe\" -N
	                -u \"C:\\...\\wt-scrollback.vim\\pager.vim\"",
	            "closeOnExit": "always",
	            "cursorShape": "filledBox",
	            "bellStyle": "none",
	            "suppressApplicationTitle": true,
	            "tabTitle": "Scrollback"
	        }
	    ]
	}
<Windows Terminal has no scrollback pager setting, so the action copies the
whole buffer as HTML and opens the pager's hidden profile in a zoomed pane.
Without animations the pager appears at once. Old settings.json files have
the key binding as "keys" in the action.

The pager runs a helper that reads the HTML from the clipboard and empties
it, and finds the pane by reading the other panes' consoles. Its C# source
is in wt-scrollback.ps1, which builds it into
%LOCALAPPDATA%\wt-scrollback.vim\wt-scrollback.exe on first use.

The pager sets the font size of the pane, of its profile or zoomed with
ctrl+= or ctrl+wheel, on its own profile in settings.json. Windows Terminal
applies it to the open pager, from then on it opens with it.
